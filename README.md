# 부산항 노선별 항만물류지표


**EDA**

- 대기시간이 낮고 항만정시성이 높을수록 운영효율성이 좋다. (최보배)
  - 대기시간이 낮을수록 효율성이 좋다고 판단할 수 있다.
  - 항만별 정시성이 0에 수렴할수록 효율성이 좋다고 판단할 수 있다.
- 항해시간은 각 노선별 따로 구해서 평균에서 박스수염을 통해 이상치 분석 (하주영)
  - 각 노선별로 월별 항해시간을 비교하여 이상치 확인 
- 종합지표(KPLI)를 어떻게 구했는지 (노선별 지표 총합 후 비교) (이재연)
  - 종합지표와 노선별 지표의 상관관계 확인
- 노선별 항만 효율성 데이터와 물동량 데이터의 상관관계 비교 (구서경)
  - port-mis에서 보니까 월로 선택해도 25년,26년 나오던데 월별데이터는 어디있더라...
